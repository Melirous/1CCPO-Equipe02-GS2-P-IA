# Testes com participantes humanos

O arquivo `testes_usuarios.csv` é apenas um **modelo vazio**, para registrar
tempos de tarefa e notas de facilidade de uso caso sejam realizados testes
com pessoas externas ao grupo. Não foram coletadas nem inventadas avaliações
humanas neste repositório.

Os resultados das **cinco personas fictícias**, geradas com o agente v2 e o
Ollama, estão em [`../resultados_personas_llm.csv`](../resultados_personas_llm.csv).
Esses resultados avaliam a presença de fatos nas respostas, não a experiência
de uso por participantes reais.
